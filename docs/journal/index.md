# Journal

A short entry for a day when I learned something worth keeping. Entries are
filed as `journal/<year>/<month>/<date>.md` and the sidebar lists the newest
first.

These are intentionally rough. If an entry turns into something I understand
properly, it graduates into a note under [AI](/ai/) or
[Software Engineering](/software-engineering/) and the journal entry links to
it.
